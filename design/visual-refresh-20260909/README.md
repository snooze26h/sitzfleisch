## 观察与方向

当前问题包括：多个面板的视觉重量接近；专注区域内部有较多未组织的空白；小图标缺少家族特征；开始、专注、暂停与历史页面的视觉变化较少。

建议围绕现有折带 S 扩展一套“时间折页”元素。先改今天页，让主计时、任务和配额形成清楚层次；再把同一套元素应用到历史、设置与浏览器拦截页。保持现在精简后的操作数量。

## 专属元素怎么用

| 元素 | 具体表现 | 对应位置与状态 | 实现方式 |
| --- | --- | --- | --- |
| 展开的时间折带 | 一段骨白折带、一个朱红切面，形成与应用图标一致的形体 | 开始页标题旁；引导到当天安排与开始按钮 | 生成独立素材，作为本地图片 |
| 停靠的折带 | 同一物体轻轻折回、靠在底座上 | 暂停状态；与暂停时长一起出现 | 生成同系列变体，状态切换时短暂淡入 |
| 归档的折页 | 已折好的薄片有序叠放，保留一个红色端面 | 收工完成、历史空态 | 生成同系列变体；不承担数据编码 |
| 当前格的折角 | 当前任务面板一角有与品牌一致的窄红切面 | 运行状态；静止时也能识别当前格 | CSS / SVG，跟随真实状态 |
| 导航图标家族 | 今天是有刻度的折页、历史是叠页、设置是带切口的调节片 | 侧栏的三个核心入口 | 用生成稿确定形体，最终绘制 16/20/24px SVG |
| 细腻的底板材质 | 低对比的纸纤维或细磨砂，同一主色内有层次 | 开始页和空态的局部背景 | 一张可复用纹理，控制透明度和压缩体积 |
| 由记录形成的页边 | 完成一格后，历史中的真实记录出现一个小折角 | 当天时间轴或历史条目 | 由现有记录驱动的 SVG / CSS；不新增积分或等级 |

大图体现材质与形体；小图标、文字、数字和时间轴用代码保持清晰。正文与输入区使用平整底色，长时间专注时的装饰保持静止。

## 素材生成约定

官方已提供 `gpt-image-2.5-sunburst` 与 `gpt-image-2.5-flare`；本任务当前的内置图像工具没有模型选择参数，因此不能声称它一定使用 2.5。用户随后明确选择内置工具。本次生成文件的 C2PA 元数据与官方内置工具文档均指向 gpt-image-2；没有将本次素材标为 Image 2.5。

参考：[Sunburst 官方说明](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)、[Flare 官方说明](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)。

下列为本次素材要求；实际精确提示词、修订过程与选用文件见 assets.json：

- 参考图角色：现有应用图标仅作为品牌形体、材质和配色参考。
- 共同要求：骨白折带、朱红切面、石墨环境；有清楚轮廓和真实的材质层次；适合缩小到 96–240px；无文字、数字、按钮或水印；各图保持同一光源和视角。
- 开始：折带舒展开，形成可辨认的 S 或其局部，以轻盈但稳定的姿态呈现。
- 暂停：同一折带自然收回，像放下的书签；轮廓仍与开始图属于同一物体。
- 收工：同一折带收拢为有序叠页，红色切面收在末端；沉静、完成，不使用奖杯或庆祝彩屑。
- 纹理：极低对比、无方向性接缝、无文字图案，避免在正文背景产生干扰。

最终压缩文件位于 src/assets/time-fold，扩展复用图位于 browser-extension/assets；最终资源为明确的不透明背景图版，首轮棋盘格版本没有用于产品。生成原图保留在本地 `originals/` 目录，已通过 .gitignore 排除，不进仓库。首轮的 fold-open、fold-rest 与纸纹在深色改版后不再被引用，其 WebP 已从 src/assets 移除，仅原图留在本地。
