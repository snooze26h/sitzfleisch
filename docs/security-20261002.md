## 使用变化

主程序与扩展需同时更新。扩展版本为 **1.4.0**；在主程序「设置 → 网站屏蔽」复制配对码，在扩展弹窗保存一次。应用重启继续有效；重新生成配对码会撤销旧配对。旧版未认证协议无法连接新版。

精确网址、整站匹配、暂停和休息保持屏蔽、收工与完整退出解除的规则保留。新增的系统 hosts 写入大小上限为 65536 字节；超过上限时保留原文件并报错。
