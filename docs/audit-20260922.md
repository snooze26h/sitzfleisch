# 0.11.0 项目审查

日期：2026-09-22。范围包括规则核心、桌面集成、界面与状态同步、浏览器扩展、构建发布、辅助脚本及文档；重点检查最近几轮改动和主要状态路径，并运行完整检查集。

## 判断

项目的职责边界仍然清楚：`core/` 管计时与数据规则，`src-tauri/` 管系统集成，`src/` 管界面，`browser-extension/` 管浏览器拦截。没有发现需要推倒重写的依据。

问题集中在连续改动后的收尾：界面重复计算核心已经累计的数值、时间轴缺少暂停分段、旧计划清单接口和样式仍在、文档和版本标识滞后。基础测试能验证账本，但此前没有覆盖这些界面边界。因此，本轮保留结构，修复已复现问题，增加必要的回归检查。

## 后续维护项与边界

1. `src/main.ts` 集中事件、弹窗和流程编排，文件较长。下一次改动相关功能时，可逐个提取完成记录或设置控制器，不做一次性大拆分。
2. `styles.css` 与 `visual.css` 的覆盖关系明确但有重复。后续按组件逐步合并；目前保留它以降低整页回归风险。
3. **本机已安装的免密 hosts 助手不会随普通应用包自动替换。** 本轮只加固源码和随包脚本，未改系统目录或 sudoers。需要采用新助手时，按[使用说明](usage.md#免掉整站屏蔽的密码框macos)重新运行安装脚本；它仍是可选项。
4. Windows 真机、真实合盖、用户浏览器代理与所有既有标签组合未在本轮重新现场验证。源码及模拟测试通过不等同这些系统路径已经全部验证。
5. 本轮是项目级工程审查和定向修复，不是对所有可能输入、所有操作系统状态的形式化证明。
